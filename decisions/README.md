# Decisions and hypotheses

Store durable material decisions and testable hypotheses here. Do not bury them in chat summaries.

## Decision record

- `decision_id`
- `date`
- `decision_owner`
- `owning_professional_core`
- `question`
- `evidence_refs`
- `alternatives_considered`
- `decision`
- `rationale`
- `assumptions / uncertainty`
- `constraints / locks created`
- `revisit_trigger`
- `status`: `active | superseded | reversed`

## Hypothesis record

- `hypothesis_id`
- `statement`
- `originating_core`
- `grounds`
- `evidence_refs`
- `what_would_support_or_falsify`
- `proposed_test_or_observation`
- `status`: `open | testing | supported | not_supported | retired`

A hypothesis is never promoted to FACT merely because a professional core recommends acting on it.
