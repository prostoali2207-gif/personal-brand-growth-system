# Channel inventory

No channel roles or strategy are defined at bootstrap.

For each actual channel/account record:

- `channel_id`
- `platform`
- `handle / page name`
- `account_ref / URL`: only when verified
- `ownership_or_access_status`
- `connected_tools`
- `publishing_authority`
- `analytics_access`
- `current_state`
- `evidence_ref`
- `last_verified_at`
- `notes / blockers`

Do not infer that the same content, objective, audience, cadence, or CTA should be used across channels. Those are later professional decisions.
