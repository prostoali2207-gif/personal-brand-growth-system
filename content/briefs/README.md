# Content briefs

This directory begins empty by design. Do not create content strategy or briefs merely to populate it.

When an authorized content brief exists, record at minimum:

- `brief_id`
- `status`: `working | approved | superseded | cancelled`
- `source_decision_refs`
- `objective / communication job`
- `verified audience/context inputs` when available
- `verified claims / evidence refs`
- `must_preserve`
- `bounded_choices`
- `may_choose`
- `must_escalate`
- `channel/context constraints`
- `experiment_locks` when applicable
- `handoff_from`
- `handoff_to`

Do not let downstream creative silently replace approved upstream decisions.
