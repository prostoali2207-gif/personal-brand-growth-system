## What can transfer into Ali's real brand content

1. **Real artifact → simplified explanatory animation.** When an approved brief calls for a complex CRM/SaaS/system concept, begin with a verifiable screen or architecture evidence. Then animate a *clearly illustrative* diagram only as needed. In 9:16, recompose text and cards for phone legibility.
2. **Idea/shot treatment before AI generation.** For a visual sequence, create 2–3 *meaningfully different* approaches for the same exact communication purpose (not cosmetic variations). Select by correctness, comprehension, time/budget and feasibility; don't demand “3–5” as a universal quota.
3. **Draft → inspect → repair → final.** First render is provisional. Save actual version, edit decisions, frame-level issues, tool versions/assets and permissions. Iterate at the responsible layer.
4. **Continuity across shots.** Track diagram/character/object geometry, orientation, labels and state transitions. No animated UI state may imply an unimplemented feature, invented customer or fabricated project outcome.
