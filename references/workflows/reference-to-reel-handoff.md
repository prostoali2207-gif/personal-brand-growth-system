# Reference → Reel → Claude / editor handoff

This is **applied coordination**, not a new professional core or a claim that Claude autonomously produces polished finished edits.

## Routing and order

`approved real project/fact packet + actual source files`
→ `Market & Competitive Intelligence 1.0.0 + Creative Reference Intelligence 0.4 CANDIDATE` (choose evidence-backed comparable mechanisms)
→ `Content Architecture` (when story structure must be chosen within approved strategy)
→ `Social Content Creative 0.1.0` (exact approved speech/text/visual communication jobs)
→ `Video Editing & Post-Production 0.1.0` (source inspection, assembly, edit, finish, export, **artifact-first QC**)
→ `human approval` → publication outside this procedure.

Check upstream version/status on material reuse. The video-editing core's qualification is limited; subjective real-media execution quality needs actual render/inspection and human comparative review.

## Steps for a reference-led edit

1. **Intake.** Record working brief, target platform/format, intended audience/message, actual file list, source identity and permissions, exact voice/script/subtitles, facts, privacy, no-music rule, prior approvals and experiment locks. Unknowns are marked, not filled.
2. **Reference selection.** Search `references/catalog.json`, read the full source card; verify media access. Choose up to 3 distinct mechanisms tied to a semantic block, not 3 arbitrary animations. Mark `TEST` if transfer is unproven.
3. **Semantic edit plan.** Source timestamps -> meaningful beats -> chosen takes/screens -> intended viewer understanding -> proof required -> overlay/graphic (if any). Keep factual before/after chronological and avoid deceptive crops/time edits.
4. **Rough cut first.** Check clarity and continuity at phone size without motion polish; route poor source/brief coverage upstream. Do not treat more effects as a solution to weak proof.
5. **Finishing.** Timed exact Russian captions (accent included), safe mobile positioning, graphics only at needed beats, speech-first audio, no music, restrained sound design (if authorized), conservative color matching. Preserve original project assets.
6. **Export and QC.** Decode actual output; validate dimensions/duration/audio; visually inspect opening, every proof frame/overlay, captions, transitions and ending. Check meaning with screen muted and intelligibility with screen not viewed. Do **not** say QC passed solely because a command or timeline completed.
7. **Review and learning.** User reviews render; log defects at responsible layer; store chosen reference IDs and mechanisms in the content handoff. Separate a subjective quality note from measured retention/leads.

## Paste-ready task brief for Claude or another editor

```text
ROLE: Editing executor inside approved brief. Do not choose positioning, invent facts, make rights decisions, or publish.
INPUTS:
- Project/brief ID: [actual]
- Real source media, timestamps and file hashes: [paths/IDs]
- Approved exact speech, captions and factual claims: [verbatim]
- Platform/output requirements: [current verified specifications]
- Brand restrictions: no music; no fake proof/metrics; mask private customer data
- Reference cards: REF-XXXX [exact card link]
- Source reference video accessible? [YES URL/path | NO]
- Selected mechanisms and intended communication jobs:
  (1) [mechanism, ref timecode, beat, why]
  (2) [optional]
- Non-transferable elements: copied style, logo, likeness, music, distinctive graphics
- Locked experiment variables: [or none]
TASK:
1. Inspect supplied files and report any missing critical asset/fact.
2. Build a semantic beat map and rough-cut plan BEFORE effects.
3. Create a reversible edit using the approved material (if render tools are available).
4. Produce render; verify technical details and actually inspect exported frames/audio.
5. Return: rendered file/link if made; timeline/edit decisions; assets and transforms;
   issues/QC evidence; exact version and next approval step.
DO NOT:
- claim the reference was viewed if it is not accessible
- fabricate a render, QC pass, published post or business outcome
- copy signature creative expression
- replace verified speech with paraphrases without approval
```

## Minimum handoff record

`from_core | to_core | brief_id | reference_ids+timecodes | mechanism+job | true facts and evidence | exact script | asset paths/permissions | constraints and locks | unresolved issues | target render | QC evidence | user approval`

The first entry REF-0001 is a **single-artifact inspected candidate**. It can inform a bounded editing test now; it cannot establish a general elite standard without independent/comparable work and further verification.
