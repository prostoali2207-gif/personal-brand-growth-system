## Admission levels

- `DISCOVERED`: identified only; original media not inspected. **Not** eligible as a creative benchmark.
- `INSPECTED_SINGLE_ARTIFACT`: actual artifact inspected; transferable mechanisms extracted, but creator-level elite/repeated excellence **not established**. Eligible for bounded experimentation.
- `BENCHMARK_READY`: artifact(s) inspected, source/author provenance checked, useful comparison and professional evidence class recorded; exact task fit established. Never infer business outcomes from views/appearance.
- `ARCHIVED`: superseded, inaccessible or disproven.

Evidence classes: `CONTEXTUAL_CANDIDATE`, `CRAFT_EXPERT`, `REPEATED_OBSERVED`, `OUTCOME_EVIDENCED`, `UNVERIFIED`. They describe **what is supported**, not a universal quality score. A first-party user favorite is valuable taste evidence, not independent elite validation.

## Mandatory use (conditional)

When an editing/creative task **materially depends on references or craft calibration**:
1. Read this catalog, select by `use_cases`, medium and evidence status.
2. Reopen the actual artifact where accessible, inspect the relevant timestamp, and acknowledge if the underlying media is unavailable. **A card is not a substitute for viewing.**
3. Follow upstream Market & Competitive Intelligence 1.0.0 and Creative Reference Intelligence 0.4 **CANDIDATE / NOT QUALIFIED** for discovery/evidence. Handoff to Social Content Creative 0.1.0 for script/visual intentions and Video Editing & Post-Production 0.1.0 for timeline/audio/graphics/QC. All professional-core status claims are version- and scope-limited.
4. Select *one to three* useful **mechanisms**, not a copied visual skin. Mark `ADOPT / ADAPT / REJECT / TEST` and the actual communication job.
5. For an approved Reel, use the [editor handoff](workflows/reference-to-reel-handoff.md), preserving real project facts, exact copy, constraints, asset identity, and user approval.
6. Inspect the resulting render on mobile and compare the actual edit with its intended communication job. Mark unmeasured hypotheses as such.

For no reference-dependent decision, do not load the library by ritual.
