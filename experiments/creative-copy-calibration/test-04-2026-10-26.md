## Blind comparison contract
Language conversational Russian, 25–35 sec; nontechnical business owner audience; both scripts share facts, production footprint and project. Only opening/sequence differs:
- A: inconvenient repetition -> decision -> concrete flow, conflict/why route.
- B: walkthrough first -> practical grouping benefit, demonstration-first route.
Both drafted in a single assistant context, not independent model treatments. Labels held until user judgment.

### A — decision-first
«Если на одну машину нужны три запчасти, зачем три раза вводить марку, модель и год? Мы сделали на сайте одну заявку, куда можно добавить сразу несколько деталей. Причём их не обязательно называть точно: можно описать или приложить фото. На телефоне форма идёт в три шага: автомобиль, детали, контакт. В итоге менеджер получает один запрос со всеми позициями. Без каталога и корзины — здесь задача совсем другая: разобраться, что человек ищет».

### B — walkthrough-first
«На этом сайте поиск запчастей начинается с простой формы. Сначала указываешь машину — марку, модель, год. Потом добавляешь нужную деталь: название, описание или фотографию. Если деталей несколько, добавляешь их в ту же заявку, а не заполняешь данные машины заново. Последний шаг — контакт. Всё отправляется одним запросом менеджеру. Так устроен сайт, которому для своей задачи не нужны ни каталог, ни корзина».

## User feedback / error correction — 2026-10-26
Exact direct user preference: **"мне кажется вариант B лучше как-то посолидней"**. Status `USER_PREF_B / one rater` (viewer voice/seriousness preference, no retention or performance conclusion).
Additional observed production failure: User noticed recurring long em dashes in both texts and the artificial `не X, а Y` rhetorical tic in ChatGPT-assisted scripts. Classify as `FAILURE_REPORT / USER_STYLE_PREFERENCE`, not public content or evidence that any feature proves AI provenance.

**Blind mapping reveal:** B was `walkthrough-first`; A was `inconvenient repetition -> decision`. In Test 03 the user also preferred B, but Test 03 B was `problem-first`. Thus the generalization `user universally prefers problem-first hooks` is NOT supported by these cross-test arm labels. The supported overlap is a preference for clear, credible, spoken-language handling of real facts. Neither creative mechanism is universally proven.
