# Analytics

This directory stores observed measurements, snapshots and professional analyses. It is not the source for invented vanity metrics or causal claims.

For each snapshot/analysis record:

- `analytics_id`
- `source_system`
- `channel / content / experiment scope`
- `time_window`
- `retrieved_at`
- `raw_or_export_ref`
- `metric_definitions`
- `filters / denominators`
- `data_quality_notes`
- `observations`
- `professional_interpretation`
- `owning_core`
- `causal_claim_ceiling`
- `decision_or_handoff_refs`

Preserve raw-source provenance when possible. Distinguish measurement from interpretation and correlation from causal evidence.
