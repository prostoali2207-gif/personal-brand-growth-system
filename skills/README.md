# Рабочие скиллы личного бренда

Решение Али, 2026-10-17: скиллы строятся по правилам упаковки знаний архитектора (короткое ядро → модули знаний → референсы → живой поиск → реестр источников с датами → проверка на реальной задаче), **без** квалификации, статусов кандидатов и гейтов.

Проверка скилла = прогнать на реальном посте/задаче, честно оценить, исправить слабое место в нужном файле.

| Скилл | Что делает | Статус |
|---|---|---|
| `instagram-content/` | Reels, карусели, подписи, субтитры | рабочий, проверен на посте №1 (2026-10-17) |
| `meta-ads/` | Реклама в Meta | план |
| `whatsapp-sales/` | Ответы на заявки и продажа | план |
| `offer-packaging/` | Профиль, пакеты, тексты | план |
