## Applied implication for an empty account

Do **not** make the first post a generic "who I am / what I do" introduction if a stronger real-work artifact exists.

For the first batch:
- let category emerge across multiple real project posts;
- each post should carry one buyer-readable problem/decision;
- use different service modules across the portfolio rather than forcing breadth into every asset;
- reserve orientation/introduction content as a later profile-navigation tool if actual profile confusion appears.

- six tutorials with no real artifacts;
- AI/tool news as the launch identity;
- one FleetDesk-heavy run that captures the whole category;
- abstract "systems thinking" without visible work;
