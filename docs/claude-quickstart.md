# Как пользоваться Claude с проектом личного бренда

Это инструкция для владельца проекта. **Ничего устанавливать или писать код для первого теста не нужно.**

## Вариант A. Обычный Claude (claude.ai, чат/Project) — начать отсюда

1. Открой [Claude Projects](https://claude.ai/projects). Создай проект «Личный бренд» или открой существующий.
2. В блоке знаний проекта нажми `+` -> `GitHub` и выбери репозиторий `prostoali2207-gif/personal-brand-growth-system`. Если GitHub ещё не подключён, пройди авторизацию.
3. В выборе файлов добавь **минимальный набор**:
   - `CLAUDE.md` (быстрый навигатор);
   - `AGENTS.md` (обязательные подробные правила);
   - `professional-cores/registry.md` (маршрутизация профессий);
   - `references/README.md`, `references/catalog.json`, `references/entries/REF-0001-claude-editing-lesson.md`, `references/entries/REF-0002-ai-motion-design.md` и `references/workflows/reference-to-reel-handoff.md`.
4. Открой `Set project instructions`, если доступно, и вставь **короткое правило** ниже. Это важно: GitHub-вложение даёт Claude *контент*, но не обязательно автоматически исполняет синтаксис `@AGENTS.md`, предназначенный для Claude Code.
5. Отправь **первое проверочное сообщение** ниже. Убедись, что Claude отвечает по реальным файлам, а не придумывает содержимое.
6. После обновления репозитория используй `Sync` / `Sync now` в знаниях проекта, чтобы подтянуть новые версии файлов. Через `Configure files` можно добавить дополнительные папки по конкретной задаче.

### Короткое правило для Project instructions

```text
Работаем над личным профессиональным брендом Ali на основе реальных проектов.
Перед профессиональными решениями учитывай AGENTS.md, проверяй реальный статус нужного professional core в professional-ai-agents и не подменяй его собственными советами.
Для референсов используй references/catalog.json, затем точную карточку и references/workflows/reference-to-reel-handoff.md.
Не придумывай клиентов, опыт, метрики, использованные инструменты и готовые результаты.
Не называй показанные в роликах приёмы доказанно эффективными без проверки.
Видеофайлы референсов в GitHub отсутствуют; не утверждай, что видел видео, если тебе его не дали.
Не вставляй музыку в Reels. Не публикуй и не изменяй внешние системы без моего разрешения.
Отвечай коротко по-русски, по делу. Если нужен доступ к файлу или инструменту, назови ровно что отсутствует.
```

### Первое проверочное сообщение

```text
Проверь, видишь ли ты файлы CLAUDE.md, AGENTS.md и references/catalog.json из GitHub.
Ничего не изменяй. Назови REF-0001 и REF-0002, их разные задачи и одно конкретное применение каждого для моего Reels про реальный CRM/сайт.
Скажи, какие документы professional-ai-agents тебе недоступны.
Не утверждай, что видел исходные видео: они не хранятся в GitHub.
```

### Когда понадобится монтаж

Дай Claude исходные видео/скринкасты, одобренную речь/субтитры и задачу. Для первого раза попроси **монтажный план и список ассетов**. Только после этого проси выполнить монтаж, если Claude имеет доступ к инструментам редактирования и экспорта. GitHub-коннектор сам по себе **не является видеоредактором** и не предоставляет автоматически доступ к истории коммитов/PR.

## Вариант B. Claude Code — когда захочешь перейти к выполнению

1. Открой checkout репозитория как рабочую папку в Claude Code. Убедись, что есть файлы `CLAUDE.md` и `AGENTS.md`.
2. Claude Code должен подхватить корневой `CLAUDE.md`, который явно импортирует `@AGENTS.md`. Проверь `/context` или `/memory`. При устаревшей версии обнови Claude Code.
3. Попроси только: `Прочитай CLAUDE.md и каталог references. Ничего не меняй. Назови доступные референсы и предложи один тест на моём реальном материале.`
4. Для профессиональных решений дай Claude Code **реальный доступ** к `prostoali2207-gif/professional-ai-agents`; одного названия репозитория недостаточно.
5. Для монтажа также понадобятся доступные реальные медиафайлы и рабочая среда с подходящими средствами рендера/QC. Пока их нет, результат может быть только планом.

## Что важно помнить

- `AGENTS.md` остаётся источником правил; `CLAUDE.md` лишь адаптер для Claude.
- Библиотека референсов хранит **разборы**, а не оригинальные файлы 155165.mp4 и 155169.mp4.
- Подключение GitHub ещё не подтверждает, что конкретный Claude видит нужные файлы. Это проверяет первое тестовое сообщение.
